# Burger Planet Fast Food Simulator Script

Burger Planet Fast Food Simulator Script is a Roblox script designed to enhance the Burger Planet Fast Food Simulator game. It includes functionalities for auto burger, auto drive thru, and auto cook meat, providing a seamless and automated experience for players.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Navigate to the ServerScriptService in the Explorer.
4. Insert the `BurgerPlanetScript.server.lua` script into the ServerScriptService.
5. Navigate to the StarterPlayerScripts in the Explorer.
6. Insert the `RayfieldUI.client.lua` script into the StarterPlayerScripts.

## Use

1. Run the game in Roblox Studio.
2. The Rayfield UI will appear, providing buttons for Auto Burger, Auto Drive Thru, and Auto Cook Meat.
3. Click on the desired button to activate the corresponding functionality.
